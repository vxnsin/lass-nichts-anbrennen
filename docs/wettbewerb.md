# Wettbewerb

Beitrag zum JWSL-Kreativwettbewerb 2026/27 („Jugend will sich-er-leben“, Jahresthema *Brandschutz in
Ausbildung und Beruf*). **Einsendeschluss: 28.02.2027.**

## Vorgaben

| Vorgabe | Was das für uns heißt |
|---|---|
| Format frei, **Spiele ausdrücklich erlaubt** | Minecraft-Modus ist zulässig |
| Video/Audio max. **2 Minuten** | Trailer/Gameplay-Video ≤ 2:00, Videoformular nötig |
| Upload max. **3 GB** (oder per Post an Landesverband) | Release-ZIP: Plugin + Resource Pack + Welten + Anleitung + Video |
| Eigenständigkeitserklärung: **keine geschützten Elemente Dritter** | Keine gekauften Assets. **Creative-Commons-Material ist erlaubt** (laut Absprache), sofern die Lizenz es zulässt und es in `CREDITS.md` sowie in der Beitragsbeschreibung genannt wird (Regeln siehe unten). JWSL-/DGUV-Logo **nicht** ins Spiel einbauen, außer nach Rückfrage |
| **KI-Tools angeben**, eigene Leistung deutlich machen | In Beitragsbeschreibung Punkt 5 notieren, wofür KI genutzt wurde (z. B. Planung, Code-Hilfe) |
| Musikformular kennt nur: keine / JWSL-Musik / eigene | **Musik** (Hintergrundmusik, Trailer) nur eigene oder JWSL-Stücke. Für **Soundeffekte** (Alarm, Sirene, Sprühen) sind CC-Sounds okay |
| Zeit laut Formular: **8 Deutschstunden** | Im Unterricht vor allem Texte, Bauen und Programmieren außerhalb |
| DGUV darf Beitrag veröffentlichen/ändern | Passt zu einer offenen Lizenz auf GitHub |

## Lizenzregeln für fremde Assets

| Lizenz | Nutzen? | Pflicht |
|---|---|---|
| **CC0** / Public Domain | ✅ bevorzugt | Nichts, trotzdem in `CREDITS.md` eintragen |
| **CC BY** | ✅ | Urheber*in, Titel, Link, Lizenz nennen |
| **CC BY-SA** | ✅ mit Vorsicht | Wie CC BY. Veränderte Version muss unter derselben Lizenz stehen, also Asset-Lizenz des Repos daran ausrichten |
| **CC BY-NC** | ⚠️ vermeiden | Nur nicht-kommerziell. Kollidiert evtl. mit der Veröffentlichung durch die DGUV |
| **CC BY-ND** | ❌ | Keine Bearbeitung erlaubt, also nicht kürzen, schneiden oder umfärben |
| „Kostenlos“ ohne Lizenzangabe, YouTube-Rips, fremde Resource Packs | ❌ | Rechtlich unklar |

- **Gute Quellen:**
  - freesound.org (nach Lizenz filtern, CC0/CC BY)
  - Kenney.nl (CC0)
  - OpenGameArt.org (Lizenz pro Datei prüfen)
  - Pixabay Sounds (eigene Pixabay-Lizenz, Nutzung erlaubt)
- **`CREDITS.md`** im Repo: eine Zeile pro Asset mit Datei im Pack, Titel, Urheber*in, Quelle-URL, Lizenz und Änderungen. Die Liste wird auch im Spiel angezeigt (`/credits`) und kommt in die Beitragsbeschreibung (Abschnitt „Genutzte Quellen und Medien“)
- Der Pack-Builder **bricht ab**, wenn eine fremde Datei keinen Eintrag in `CREDITS.md` hat. So kann nichts Unlizenziertes ins Pack rutschen

## Vorführung in der Klasse

- **Nicht jede*r hat Minecraft Java.** Für die Vorführung reichen 1 Beamer + wenige Accounts. Multiplayer-Finale mit 2–6 Leuten
- **Schulnetz** blockiert oft Ports. Server auf eigenem Laptop im LAN oder zu Hause hosten und vorher mit der Schul-IT klären
- Die Education Edition ist Bedrock-basiert und kann sich nicht mit dem Server verbinden
- Fallback für die Einreichung ist der **2-Minuten-Trailer**. Jury und Klasse sehen damit alles, auch ohne Minecraft

## Weitere Regeln für das Repo

- Keine Namen von Mitschülern, Lehrkräften oder Mailadressen ins öffentliche Repo, nur ins Wettbewerbsformular
- Enthält das Pack CC-BY-SA-Material, müssen auch die eigenen Assets unter CC BY-SA 4.0 stehen
